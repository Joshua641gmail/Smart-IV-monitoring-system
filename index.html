Smart IV Fluid Monitoring System

A low-cost IoT prototype that tracks intravenous fluid levels in real time, identifies low and critical states, and helps caregivers respond before a bag runs empty.

Project highlights

  • Real-time fluid-level monitoring
  • Colour-coded alerts for safe response
  • LCD-based bedside display
  • ThingSpeak connectivity for remote visibility

Project overview

Addressing a common care challenge with practical monitoring.

In many hospitals and health centres, IV fluid checks are still done manually, which can delay response when a bag is nearly empty. This project introduces a simple embedded system that continuously evaluates fluid status and gives clear alerts to reduce risk and improve nursing efficiency.

What the system delivers

The prototype combines a load-cell sensor, ESP32-based control, an LCD display, LEDs, and cloud upload to provide a dependable bedside monitoring workflow.

How it works

Simple hardware, clear monitoring logic

1. Sensor input

A load cell measures the remaining fluid weight, and the system converts it into a percentage estimate of the IV bag contents.

2. Status evaluation

The controller classifies the condition as Normal, Low, or Critical based on predefined thresholds for safe monitoring.

3. Alerts and upload

LEDs and the LCD display show the current state, while ThingSpeak enables the data to be shared for further monitoring and review.
